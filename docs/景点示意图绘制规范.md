# 景点示意图绘制规范

## 地点印象插画

地点印象是旅行插画，与场地总览及室内平面图分别维护。产品登记的印象图片原文件必须为 2:1；首页、发现地点、收藏与详情统一通过 `public/lib/place-impressions.js` 获取现行图片。重绘图要包含清晰的地点标题和中文描述，沿用原有暖米色纸张、陶土橙、深绿及建筑海报风格，文字与建筑错开并留安全边距。不能用裁切、拉伸或填充空白代替完整构图。

2026-09-29 使用内置 image_gen 重绘 10 张不一致的插画，最终素材为 `public/images/places/impression/*-ai-2x1.png`，均为 1774×887；逐图提示词及路径见 `scripts/references/impression-redraw-prompts.json`。旧图片路径在前端映射到新图，不修改用户历史记录。27 张现行登记图片及占位图的原始比例由 `tests/place-impressions.test.ts` 校验。印象插画不作为地理位置、楼层布局、入口和开放范围的依据。

## 场地与室内示意图

图面使用本地 SVG；场地总览点击建筑后打开该建筑的已收录资料。真正的楼层图保留切换与放大，只有外观资料的地点显示外观说明，室外亭廊显示室外区域说明。没有可核验的室内图纸时显示资料状态，不能填入通用房间、推测的商铺编号或公共设施，也不能替未知建筑补造一个占位楼层。图纸覆盖数只比较已收录楼层，不表示建筑实际总楼层数或当前公众开放数量；功能组成图与室外区域不计为室内楼层平面图。

楼层图点击放大后，关闭大图（叉号、Esc、遮罩）返回原建筑的楼层面板，保留所选楼层、滚动位置及触发按钮焦点；再次关闭楼层面板才退出室内示意图。独立打开的地点印象大图关闭后返回原页面。

## 图形与标注

- 图纸底色为 `#f5f6f5`，墙线为 `#748aa8`，主要展区为 `#809bc5`，公共通道为 `#a0bfd2`，服务区为 `#eaf1f3`。
- 文字采用微软雅黑 / Noto Sans CJK SC。取消厚重的文字描边，保留主次层级；狭窄区域使用换行或引出标注，不能压缩成不可读的小字。
- 卫生间使用蓝色 `#176c91` 的人物符号与“卫生间”文字；出口使用绿色。设施不能仅靠颜色区分。
- 展区名称在图面中对应真实分区。卫生间、出口可以在不同实际点位重复，图例中的重复也属于正常解释。
- 外墙、通廊、中庭与楼梯的位置关系优先于装饰。家具仅作空间辨认，不代表现场数量。建筑师设计图和历史图需说明其资料性质。

共用样式和卫生间符号位于 `scripts/lib/floorplan-design.mjs`；运行 `node scripts/style-floorplans.mjs` 后嵌入各 SVG，图片可以独立显示。

## 资料与定位

上海博物馆东馆 B1–5F 依据官方导览折页（2025）重新绘制；徐家汇书院 1F–3F 依据建筑师公开设计图重新绘制。B1 功能图仍只表达功能组成，不能计为已核实的建筑平面。

上海公安博物馆保留公开 VR 导览记录的轮廓，统一版式与设施标注。武康大楼旧图中的十个商铺、公共通行区和卫生间缺乏可核验依据，已撤下该室内图；总览保留建筑入口，仅打开外观资料，不显示 1F 占位、“馆内导览”或承诺室内参观路线。桂林公园九曲长廊、湖心亭及光启公园六角亭依据已收录的空间说明标为室外区域，不将区域名称当作室内楼层。

`public/lib/place-tour-data.js` 中楼层图片的 `restroomsMapped: true` 仅表示参考资料中有可核验的卫生间标注，不能据此宣称当前现场位置已核实。面板与放大图统一说明“蓝色标记来自参考资料，现场位置及开放状态尚未复核”。资料未给出点位时不标记，说明“本层位置尚未核实，图中不作推测”；未标注不代表没有卫生间。

`public/lib/place-map-evidence.js` 登记图纸性质、资料名称和明确的资料年份。楼层图分别标为官方导览重绘、设计平面重绘、设计轮廓示意、项目导览重绘、VR 轮廓示意、空间关系示意、历史平面重绘或功能组成示意。资料年份只取已有明确依据的 2019、2022、2025 年记录；其他显示“资料时间未注明”，不能拿建筑竣工、下载、绘制或测试日期代替资料日期，也不代表现场核实日期。新增图纸未登记来源时显示“资料待核实”。

图纸依据卡在楼层图之前展示；放大图从同一图片记录取来源信息，同时保留设施说明和可展开的本层详细限制。功能图不表示位置、墙体与通行路线；设计图、VR 和旧图不宣称现状准确。来源只显示本地文字，不提供外部跳转。场地总览单独记录地理轮廓来源和读取日期，不能借用室内参考图的日期和来源来证明总览；读取日期也不是地图出版或现场核实日期。

## 室外总览校准

30 个已有总览均改为本地 SVG 轮廓图。`scripts/references/site-overviews.json` 保存 OpenStreetMap 建筑、道路、水域、绿地及已有设施坐标记录，地理数据按 ODbL 1.0 保留来源说明，完整许可文本存于 `scripts/references/ODbL-1.0.txt`；不内嵌高德截图、瓦片或外部图片链接。高德放大画面可用于人工比较，缩放更大不代表轮廓、入口或开放状态已经准确，更不能证明室内结构。

`node scripts/redraw-site-overviews.mjs` 从本地快照生成 `public/lib/place-site-geometry.js`。经纬度使用 WGS84 局部等比投影，北向朝上，比例尺随实际绘图范围计算；周边建筑不规整化，不补造道路、树木、矩形园区边界或房间。建筑中庭保留多环孔洞；道路位置沿真实折线绘制，路宽仍是绘图表达，不能作为测量数据。园区范围优先取有名称的真实边界，单体建筑取轮廓加周边区域。

建筑与已有楼层 ID 的关联保存在 `scripts/references/site-building-links.json` 及生成脚本的明确对应表。没有明确名称或唯一包含地点坐标的轮廓时，不按最近建筑或旧图位置猜测关联；以下方文字按钮保留原楼层资料入口并说明位置待核对。主建筑可点击，周边建筑只作参照，不替换原地点身份。

室外卫生间以蓝色 WC 标记、入口以绿色箭头标记，只取资料中已有且非明确私有/禁止通行的记录；附近密集同类记录合并显示，不移动原坐标。标注与文字说明错开，设施没有记录不等于不存在。室外读取日期不借给室内图，普通图面不显示用户位置。

静态 SVG 不得包含“您在这里”“我的位置”或定位图钉。原导览牌上的位置标记不能当作用户位置重绘。将来实时定位应由导航层动态绘制，并同时具有导航开启状态、当前楼层和有效的室内坐标；普通 GPS 坐标不足以推断室内房间位置。

## 检查

1. `npm run build:test`，再运行 `node --test dist/tests/place-maps.test.js dist/tests/plan-schedule-alignment.test.js`。
2. `node scripts/verify-floorplans.mjs --gallery`：通过 Edge 实际字体与变换矩阵测量全部楼层图的文字重叠、越界；公安博物馆另检查展区标注是否留在对应区域。临时输出目录包含报告和整组预览。
3. `node scripts/verify-floorplan-ui.mjs`：使用隔离浏览器及内存测试服务，检查桌面、390px、320px、深色大字及 320×568px 下的建筑入口、楼层切换、资料类型/时间、设施说明、大图拖动和待核实状态；关闭大图仍返回原楼层。功能图、设计图、历史图和官方导览在放大后保留相同依据；不操作用户数据。
4. 人工对照原始资料与预览。文字检查不能证明房间布局、比例或现状准确。
5. `node scripts/verify-site-overviews-ui.mjs`：在 1440/390/320px、浅色及深色大字共 180 组布局中测量文字、设施标记碰撞和越界，验证实际鼠标点击、放大/关闭、待核对建筑资料入口及断网后的本地绘图。`tests/site-geometry.test.ts` 检查等比距离、北向、庭院孔洞、轮廓依据与楼层入口连续性。
6. `node scripts/verify-tour-guidance-ui.mjs`：真实手机触摸建筑入口、外观说明关闭、真实楼层切换和大图返回；320px 深色大字、390px 普通及 430px 简约下检查面板溢出及 44px 关闭范围。缺图地点不提供无意义的地图放大；室外／外观说明不带错误警告色或空白撑高。此项验证说明与交互，不证明现场开放权限或图纸现状准确。
