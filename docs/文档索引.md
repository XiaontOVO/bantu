## 维护规则

新增或修复功能先更新对应唯一入口，再调整作品说明和附件中的对外范围。精确业务规则不复制到简介；测试轮次不逐页追加。未知场馆资料、真实模型和用户收益不能用自动化通过代替，公开地址须实际远程验证。

`python -X utf8 scripts/check_planning.py` 检查文档覆盖、链接、工程路径、接口与问题唯一性；`npm run check` 检查类型和自动化场景。浏览器、真实供应商、实地、用户及生产运营分别验收。

反馈闭环与待实机验收统一维护在[产品体验全盘核查](产品体验全盘核查.md)。已解决及复核撤回的反馈报告清除，原截图保留；新增反馈应包含可复现步骤及设备/网络条件。
