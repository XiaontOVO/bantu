# 伴途｜产品与交互规格

> 更新：2026-10-05。合并产品定位、模块、首页随行、页面交互、地图收藏和社区流程；本页维护现行用户行为。详细执行规则仅在[三态规范](计划与进度三态转换逻辑.md)维护，工程字段与接口仅在[工程契约](工程设计与接口契约.md)维护。

## 定位与范围

伴途面向城市散步、建筑探访与看展的自由旅行者，围绕“现在做什么、变化后怎么调整、接下来如何继续”提供行中陪伴。用户可以直接操作页面或委托 Agent；打开即可使用，不要求先创建 Trip。对外简介、差异分析和演示口径见[作品说明](作品说明与演示.md)。

主流程：找地点 → 保存方案或日计划 → 选择交通方式并出发 → 查看道路预计 → 报告到达 → 场地/楼层资料 → 完成及下一站 → 私人回顾或自选分享。地图和模型是提供信息及交互的工具，业务服务负责实际约束和写入。

产品以手机现场使用为主：定位、随行提示、地点现场、单手点选、语音／文字讲解和 Agent 小窗优先按 320–430px 竖屏设计与验收。电脑端主要服务行前整理方案、回看与运营，不作为景点现场的主要交互基准。手机进入地点现场时收起全局底部导航，保留清楚的返回入口；点选画中元素后在原页面展示正文并按偏好立即讲解，不强制滚离画面。Agent 是可拖动、可收起和关闭的独立小窗，不添加遮罩、不隐藏页面按钮或底部导航；窄矮屏仍须看得见输入和关闭入口。主要控件至少 44px 高，弱网、定位拒绝、静音与减少动态效果都应保留可用的文字路径。

后续功能与验收按“手机行中体验 → 手机行前准备 → 桌面整理”排序。现场视图隐藏重复的全局页头，手机页头只放返回／地点名／音乐／参观设置，让场景尽早进入首屏；Agent 用可拖动的轻量悬浮入口保持单手可触达，展开为非模态小聊天窗，不用大字画面标语遮挡场景元素。大屏只是适配布局，不以桌面设计反推手机。发布前需在真实 Android 与 iOS 浏览器核对 HTTPS 下的定位授权、软键盘、前后台切换、耳机／静音、弱网和长时间使用；浏览器缩屏只算预检。

## 智能伴行与共用朗读

设计目标是让用户到达地点附近时自然认识眼前的风景，而非再打开一个独立功能页。首页“智能伴行”及“我的 → 智能伴行”提供同一设置；默认关闭，主动开启后申请定位，自动朗读可独立关闭。设置按当前身份保存在本设备，切换身份互不继承。安静参观关闭主动介绍和声音，文字资料仍可手动阅读。

应用前台连续两次新鲜、误差不超过50米的GPS，在同一保守候选范围停留约20秒后，出现友好的伴途虚拟形象与短介绍卡。地点来自全部已收录目录，不要求先有计划，也不限制在七处场景；有当天计划时，处于范围内的当前站优先，绕路到其他地点仍可识别。相邻建筑难以分辨时等待更准定位，坐标缺失不猜测。候选不是实际场地边界或室内定位，不产生“已到达／完成”的执行事实。

介绍卡不锁页面或抢走当前导航，可关闭、停止／重听、追问、查看地点资料；有场景时另提供手动进入。主动到场介绍优先于旧“到场自动进入”全屏行为，旧设置保留，关闭智能伴行后恢复。正在编辑、对话、查看场景或操作面板时先等待，忙完后用新定位核对再介绍。同一计划站次按planId＋stopId去重；无计划地点在明确离开并再次稳定靠近后可重新介绍。后台立即停止定位和声音，取消未完成介绍后返回需重新稳定定位；迟到回执不能写到新账号、新目标或已关闭功能中。

模型读取服务端已收录地点资料，生成简短讲解，使用用户当前选择的官方或自接模型；不允许调用写入工具、改变进度或创建聊天记录。来源与模型失败分别呈现，失败时保留已收录资料并可重试，不把资料回退称为模型生成成功。场地开放、票价、楼层和用户感受不推断。

Agent每条助手回复提供朗读／停止按钮，完整页和悬浮窗共用；朗读保留长回复全文，按短句分段，不再截取前800字。Agent、伴行介绍、场景元素和音色试听使用同一个语音通道与“伴途共用音色”，新朗读替换旧朗读，实际开始讲解后才降低场景音乐音量。界面分别显示排队、正在朗读、完成、停止、受阻与失败；自动播放被设备限制时保留介绍及手动重试，不能将排队当作已经发声。后台、账号或聊天会话切换停止旧朗读，不自动恢复声音。设备音色供应与听感仍取决于系统，未接入云端TTS。

### 旅行成就与地点收藏册

入口为「我的 → 旅行成就」，我的页面另有收藏册入口，直接地址为 `#/achievements`。原首页足迹、旅行记忆和收藏继续保留。收藏册用现有本地印象插画与柔和渐变构成 3:4 地点卡，印象图保持 2:1；手机优先双列，宽屏增加列数，大字模式按可用宽度调整。卡面采用整幅上半部插画与材质下半部，统一标题、次数和剩余次数的对齐；不用大片混色与散落星点。升级通过珠光底色、雕刻纹样、收藏印章、金属卡框与进入视野时的一次反光体现。标题与游览数字使用本地宋体，说明和操作保留易读的界面字体；页面加上细纸纹。基础卡为浅绿，珠光卡为淡紫虹彩，流光卡为宝石蓝，珍藏卡为深翡翠与香槟金；深浅色主题均保留这些材质层级。没有到访时显示真实空态和发现地点入口，不注入示例成就。

| 同地点有效完成次数 | 卡片等级 | 视觉变化 |
| --- | --- | --- |
| 1 | 初遇 · 柔彩 | 象牙白与浅绿底色，淡色收藏印章 |
| 3 | 重逢 · 珠光 | 柔和珠光底色与紫色印章 |
| 7 | 熟悉 · 流光 | 宝石蓝底、银色纹样与进入视野时的反光 |
| 12 | 珍藏 · 星辉 | 深翡翠底、香槟金卡框、雕刻纹样与表面反光 |

卡面显示累计次数、下一等级剩余次数与进度；到顶后仍累计次数。减少动态效果偏好下不播放流光；简约模式保留收藏卡本身的名称和进度，只简化操作按钮。深色模式保留收藏卡的颜色辨识。

点击卡片展开对应地点的到访记录，显示实际完成日期和时刻、来源计划，并可进入原进度记录；旧事实没有时刻时明确写旧记录，不补造时间。「再去看看」进入地点详情，可沿既有流程加入计划或进入场景；「写下记忆」进入私人旅行记忆。全部／闪耀筛选分别展示所有已点亮卡与至少珠光等级的卡。

三个小成就分别为「旅途初章」（完成一次游览）、「城市漫游者」（5 个不同地点）、「老地方，新故事」（重访 3 个不同地点）。未解锁时显示真实进度，不设连续签到、排名或强制分享。全部成就仅当前主体可见；游客依照现有游客身份保存与绑定规则。

次数依据当前有效执行事实计算：一个 planId + stopId 只计一次，同地点的不同站次可以分别计数。归档到往日记录继续计数；纠正、删除对应执行对象后重新计算等级与徽章。浏览、定位、场景点击、收藏、私人笔记和未执行方案均不计数。Agent 在此页收到服务器核验后的收藏统计与选中地点等级，不信任浏览器自行提交的次数。

首页和侧栏共用合法目标选择：账号内旧日期仍进行中的站点优先，否则选择当前计划下一待开始站；完成和跳过不是下一站。完整安排跳转原计划日期，编辑页选中日期不擅自替换首页目标。同日重复计划、被删目标与身份变化须说明冲突或要求重选，不随便取第一份执行。

首页旅程区域依次呈现当前行动、阶段内容、四类变化入口、后续安排；地点灵感保留在其后。四类变化入口仅在目标可执行时显示（当天安排或允许跨夜继续的活动），包括准备出发阶段；未来日期的行前预览不展示，也不允许记录实时进度，用户仍可通过Agent或编辑页调整未来安排。计划名、日期、来源天数与进度组成地点卡外的旅程概览；当前行动卡以地点为主标题；仅拆分与来源天数吻合的自动名称后缀，自定义名称和旧记录保留原文。

## 随行阶段与行为

定位有效但道路前置查询失败时，同样先说明“路线暂时无法核对”，提供取消、重新查询和明确先记录。先记录仅保存真实出发，预计保持待估；失败不触发另一轮隐藏估算。Agent 已保存笔记但后续回复中断时明确报告这两种结果，避免用户误以为保存失败而重复发送。

Agent 保存或修改日计划成功后，可点“回到首页随行”继续具体计划；方案仍在方案页查看。新一句话修改按本次指令执行，不延续旧聊天里的创建要求；已有实际出发、到达和完成不能被改时覆盖。

首页当前站确认到达后，已支持场景的地点显示同排同高的“进入场景”和“结束游览”。场景等待可取消，失败在原卡重试；当前站点或计划版本已变化时旧加载不会跳转。其他地点保留场地资料，不显示无效场景入口。进入场景不等于记录到达，点画中元素显示讲解与按偏好播放；小窗保持当前地点和计划上下文。

最后一站完成后点“查看这次旅行记录”，直接打开该计划产生的私人旅程。等待、失败和无对应记录均保留原页及已记录进度；跳转读取与账号、导航绑定。用户可委托 Agent 把自己的原话补进同一记录；不新建重复旅程，不把模型编写的感受当成用户经历，公开分享仍由本人明确选择。

| 阶段 | 页面依据与主动作 |
| --- | --- |
| 无计划 | 展示找地点、安排及对话入口 |
| 出发前 | 下一站、交通方式、道路估算、已有开放/预约资料、出发 |
| 前往中 | 当前站路线、预计到达、预计冲突；我已到达/中止 |
| 游览中 | 实际到达、场地总览、建筑/楼层、设施说明；完成这一站 |
| 已收尾 | 刷新权威进度，接续下一站；最后一站提供回顾及记忆入口 |
| 冲突或失效 | 明确目标或身份变化，重选/处理冲突 |

阶段是既有计划与进度的派生展示，不另建执行状态机。打开随行不代表出发，GPS 接近不代表到达，超时不代表完成。查看未来计划不提供实时出发操作；旧活动不收尾不能另开一站。

定位失败展示原因、重试与“先记录已出发，路线待估”；只有明确选择降级才记录事实。有效设备位置必须合法、新鲜且精度合格，具名起点标明来源；不把上一站、计划城市或固定坐标当成当前位置。

地图重新定位等待期间，用户后来选择的手动起点、站点路线或全程路线优先；先改起点再改回也不会被旧定位覆盖。新的设备位置仍更新蓝点，旧定位结果不抢回视野或改回起终点模式，旧失败不覆盖后来选择的路线反馈。未改变选择时，正常定位成功及失败仍有明确反馈，等待结束恢复操作按钮。

首页前台可监听位置、节流查询道路预计与天气；离开或隐藏时停止额外监听、轮询，取消过期响应。ETA 更新只改变预测，不写到达、出发或真实延误；计划、预计、实际时间分别显示，跨日标日期。天气是预报，目录开放资料可能为近似或样例，须行前核实。

## 地点详情的打开与恢复

地点详情按链接中的地点编号单独读取，不依赖当前搜索条件、目录分页或已加载的地图。打开后立即切入详情页；已有资料先展示并标明核对中，没有资料显示读取状态和返回入口。正常读取补齐当前地点，不能把详情塞进原搜索结果或改变筛选条件。同一页切换另一地点也视为新导航，旧成功／错误回执不能跳回旧地点或覆盖当前读取。

网络或服务失败说明“暂未加载”，提供原位重试；只有详情接口确认地点不存在才显示不可查看，仍可重新核对。重试清除旧错误、恢复读取反馈，读取期间可返回。普通、大字与简约模式保持同排按钮等高，简约模式只隐藏图文按钮的文字，辅助说明仍可读。

公开地点撤回后，旅者收藏、计划或往日资料中的地点快照保留供回顾，标明“已保存的地点资料”。不将旧目录、搜索或地图结果当作仍然公开的证据；暂不能加入新计划、打开场景或编辑该地点的评价、标签、备注。已有收藏仍可取消。重新核对确认恢复公开后恢复正常操作；不删除已有计划、记忆或执行事实。私有标签与备注随当前账号隔离；本轮不新增完整离线参观或离线写入能力。

地点总览的建筑入口按资料性质打开：武康大楼只看外观与周边布局，室外亭廊看区域资料；有楼层图的建筑才提供楼层切换与放大。公园不显示“馆内 0/0 层”，未知轮廓不补造一层；覆盖数是已收录楼层图的覆盖，功能组成图不计为建筑平面。说明不承诺公众可进入，也不代表现场布局核实。无总览图时隐藏无意义的放大入口；外观与室外资料卡依内容撑高，正常说明不用警告色，关闭按钮保持 44px。

## 地点现场与全程 Agent 陪伴：七处场景试点

上海自然博物馆试点已接入地点详情与全局 Agent 小窗：一幅原创场景图、建筑外观／L1“生命长河”／B1“演化之道”三个可选元素、资料依据、原有总览与楼层图入口、可控的原创合成音乐及文字／浏览器朗读。武康大楼有独立的原创街角场景与“红砖立面／弧形转角／街口视角”三个室外元素，只讲可见外观，不虚构可进入的室内楼层。徐家汇书院有原创阅读场景及“书墙／1F 儿童阅览／2F 阅读”三个入口，楼层入口能返回已有平面图；画中的书架与座位不当作真实房间布局。徐家汇公园以已收录的烟囱和步道实拍为参考，组合“红砖烟囱／林荫步道／高架步道”三个室外主题；画面不表示这些元素的真实相邻关系，找路回到场地总览。龙华寺依据本地收录的塔与庭院照片绘制塔檐、殿檐和香炉三个室外主题，不把组合画面当作实际院落布局或礼佛路线。桂林公园依据本地收录的竹林门景与亭台照片绘制月洞门、竹影和木构游廊；画面不推断圆门与游廊相连，也不保证园内分区当前开放。西岸美术馆依据已收录的外观照片绘制立面格线、方正转角与广场树影三个可点选元素，不把旧海报当作当前展览，也不推断参观入口、室内展品或开放范围。七处使用不同的本地合成音乐。Agent 小窗复用真实模型工具链，服务端重新核对地点、元素和本人计划；已验证一句话保存私人记忆及高亮元素。目标仍是让伴途从“安排去哪儿”延伸到“在这里值得看什么、为何值得看、如何继续旅行”。场景插画不承担导航与设施查询，也不代表实景或实时室内定位。

地点详情将“加入计划”（编辑中为“加入草稿”）与“进入场景”放在同一主要操作区：两按钮等宽、54px 高，图标与文字居中；操作区位于实拍照片分区上方，随页面正常滚动，不使用悬浮或吸底定位；“进入场景”采用画面与进入箭头，区别于地图导航图标。简约模式只隐藏文字，保留按钮宽度与点击范围。不支持现场内容的地点只显示整行加入按钮。

目前只有这七处地点有现场内容，其余地点尚未开放该入口。到场自动进入须旅者主动开启，依据计划中当前 `stopId`、应用前台连续两次新鲜且精度合格的定位和约 20 秒停留；使用高德目录 GCJ02 坐标转换成手机 GPS 的 WGS84 后建立保守圆形候选区，并非经核实的场地边界，不记录“已到达”。室内元素只通过旅者点选。已核对的资料正文始终显示，模型短讲解仅作补充；模型内容明显与当前地点或元素无关时回退到已核对文字，模型失败也不会让楼层限制消失。进入场景不自动发声；默认在旅者点击画中元素时播放资料讲解与音乐，可在参观设置分别关闭。朗读优先选择设备已有的自然中文音色，并支持选择及试听；没有新增云端 TTS 服务，不同设备的音质与支持程度仍有差异。

### 一次参观的体验

旅者可从地点详情手动打开现场；已开启到场自动进入且满足前述候选条件时，应用在前台自动切入。进入场景不会自动记录“已到达”，该事实仍由旅者报告。现行场景以手机横屏为主要体验：七处画作统一为 AI 生成的 2:1 宽幅，横屏时全幅显示，不裁切关键元素；画面只保留44px返回按钮，收起全屏、音乐、设置、浮动Agent和讲解工具栏。画中元素继续可点击，文字窗口可拖动，点击画面空白处收起讲解。音乐与讲解按参观偏好触发；竖屏保留音频和设置，可直接点画，也可点“横屏探索”：浏览器支持时进入全屏并请求横向，不支持锁向则由用户自然旋转手机，不能承诺所有浏览器强制横屏。图片加载失败的文字恢复入口继续可用。

直接点红砖、书墙、塔檐等画中元素，透明形状点击区与新画作使用同一百分比坐标；不出现漂浮标签按钮。点选立即播放短讲解及 BGM（服从参观设置），文字在画面侧边浮现；关闭文字停止本段朗读并保留音乐，不退出场景。浮层有重听、追问伴途、地图／楼层资料、私人记录和详细资料入口。竖屏文字卡放在画作下缘，避免遮住窄幅点击区；“探索与资料”也提供 44px 的文字元素列表作为小元素与无障碍替代。资料依据、原始限制与模型补充集中在按需展开的详情中，短讲解不能替代真实设施和楼层资料。

讲解窗口可抓住标题区拖动，也可聚焦标题后用方向键移动。拖动超过阈值才移动，不触发画中元素；正文仍可滚动。竖屏保留关闭与重听等操作，横屏点击画面空白处收起文字，不显示额外工具按钮。位置在当前页面会话内按身份与场景保留，重绘、收起重开及地图往返不重置；旋转或改变可用视口时限制在页头下方和屏幕内。竖屏保留原窗口占位以避免拖动时页面跳动，不承诺刷新或跨设备保存几何位置。

伴途聊天小窗使用同一行的头像／标题、完整对话、收起与关闭工具栏；“附带本页”独立为上下文行。照片、输入和发送处于同一条 44px 高的输入栏，空对话只提供两项短建议；完整页面仍保留原建议与完整内容。矮屏收起辅助上下文及副标题，优先保留消息、输入与三项工具；不同于关闭悬浮入口。行程并排显示地点名称、前往及游览时，三项标题使用共同的标题区高度及中心线；有 44px 调整时间按钮时，两项阶段的标题和时间行一起对齐，手机堆叠时保持一致的标题栏高度。

光影与少量环境微粒只作轻量氛围，不移动画面或点击区域；安静模式及减少动态效果停止动画。竖屏中的伴途小窗继续可移动、关闭，不锁背景，在有空间时避让讲解卡及提醒；横屏画面暂时隐藏小窗，返回或转回竖屏恢复。设置和资料等模态面板打开时，小窗与页面一同临时不可交互；关闭恢复。旅者可以在竖屏点“记下此刻”或在详情里“整理为私人记忆”委托Agent，发送后以工具回执为准，不推断实地到访与感受。往返楼层图保留当前探索；离场或转到其他页面释放本次请求的全屏。应用切入后台停止音乐、朗读与音色试听，并释放横向锁；返回场景更新播放状态，不自动恢复声音。迟到的横屏请求不能重新锁住首页，也不能取消后来进入的场景。自动朗读优先普通话，再比较同语言的自然音色，手动选择仍优先。

音乐尚在启动时，按钮显示加载图标并提供“取消音乐启动”的无障碍名称，同一按钮可取消；减少动态效果时图标静止。取消、切页、切后台或在设置中关闭音乐不报播放错误，设备初始化失败则明确提示并允许重试。当前元素的讲解只接受本次最新请求，较早的欢迎、重复点选与前后台切换前的回复不能覆盖新内容。其他页面切换账号时，当前页保留原账号与未发送输入，同时暂停声音、全屏、定位提示及包括聊天小窗在内的后台交互；重新核对原账号后恢复操作与正确的播放状态，不自动发声。暂停期间即使原弹层被迟到的操作关闭，也不能解锁页面；恢复账号后不会留下已关闭弹层的交互锁。


首个试点选上海自然博物馆：绘制建筑外观与公开展区相衔接的分层场景，优先选已有资料支持的建筑外观、L1“生命长河”、B1“演化之道”三个元素。每个元素必须有名称、可核查的事实摘要、资料来源与核对日期、场景中的艺术表达、互动动作和资料不足时的降级文案；动态展项、实时开放及具体室内位置未经核实不得编造。图层可有轻微视差、昼夜色彩和焦点动画，但低性能设备、大字及减少动态效果设置下保留静态等价体验。场景、热点和主要操作支持键盘及屏幕阅读器，不靠颜色识别。

### 手动进入场景的反馈

地点页仍在实拍照片上方并排显示两项静态操作。进入场景后，原按钮暂时变为“取消等待”，下面显示准备状态；两按钮保持同高，加入计划仍可用。点击取消立即停止该请求，并恢复入口和键盘焦点；重绘保留等待状态，不重复读取。当前失败在原位显示原因与“重试进入”，不再同时弹出第二条错误提示；网络错误以中文说明。重试清除旧错误，成功后清除等待状态。简约模式仍用图标表示按钮，状态文案保持可读。

首页当前站点把地点名称与站次放在同一标题行，计划时间与游览时长并排，开放及预约时段各占紧凑的信息行；长名称、多个时段和大字模式自然换行，不以固定高度裁切。交通选择与出发／到达按钮同排同高，点击区域至少 48px；游览中的完成按钮仍占整行，中止出发另行显示。简约模式保留该行布局及点击范围。地点页的两项操作保持 54px 同宽同高，随文档滚动，置于实拍照片标题和照片之前。进入场景的箭头从画框外指向框内，表示进入画面，与普通播放入口区分。

首页路线更新立即区分“正在取得设备定位”和“正在核对道路路线”，原更新按钮变为“取消更新”；取消恢复入口并保留原有效路线，迟到回调不能采用新位置或覆盖后一次更新。定位拒绝、不可用、超时及网络失败显示中文说明，可以再次更新；地图和目的地不因等待或失败消失。手机路线标题与操作同排，大字窄屏不被装饰图标挤压。当前站点按账号缓存详情，不把它插入筛选后的地点列表；离页、切换到访或账号暂停后，旧读取和旧定位监听均失效。参观提示只说查看已收录资料，不暗示所有建筑都可进入室内。

手动选择优先于后台自动入场：有效手动请求等待期间，自动候选不能取消或替换它。来源界面绑定具体地点、场景、帖子或计划历史，不仅绑定页面类型；即使不离开地点页而切换另一地点，也撤销原请求。取消、来源切换、账号暂停或后台中断后，旧成功／失败不能重新打开场景或清空后来重试。原位错误只属于发起身份、导航版本和地点，不跨页面冒充新错误。

### 场景切换与返回

同一页面切换不同地点的链接，也必须更新画面、资料和伴途上下文，不能仅改变地址。新地点或新的计划站点重新开始探索；同一次参观从场地总览或楼层图返回，保留点选元素与已探索记录。加载新地点时显示准备状态，伴途只附带目标地点，不引用上一处的元素或名称。

手动与到场自动进入共用加载规则：只采用最近一次请求，绑定发起账号、页面和导航版本。用户已切页、换账号、关闭场景或应用暂停时，迟到成功与失败都不能开场景、退出当前页面或覆盖新资料。当前且仍允许自动入场的失败给出反馈并保留原页面；当前深链接失败返回对应地点详情。加载中返回可以取消请求；前台恢复时重新准备被中断的场景，不自动恢复声音。进入场景与这些恢复操作都不写入到达、完成或其他旅行事实。

自动入场在触发前与资料返回后都核对用户操作：聊天小窗、发送／照片处理、计划草稿或编辑、模态面板、输入焦点都应让出当前操作；完整 Agent 页不自动切走。关闭自动进入立即取消待完成的自动请求及定位检测，手动入场仍可用。因操作忙碌取消的尝试不算已自动打开，重新检测时需要新的合格定位与停留，收起聊天或面板不会直接重放旧判断。定位资料与回调绑定当前检测轮次；旧请求失败、旧 GPS 成功或错误不能关闭新监听、重置新停留或触发入场。

### 画面异常时继续参观

场景画面加载期间显示明确的准备状态，画面尚未可用时禁用隐藏的画中热点，可直接重新加载或转入文字探索。加载失败展示主题列表，主题继续使用已有资料、讲解偏好和探索记录；重载只处理图片，不清空选择、探索、日计划或进度。画面迟到加载成功时保留旅者主动选择的文字界面，可明确回到画面；恢复正常画面后，文字操作区隐藏，不给画中元素增加常驻按钮。手机横屏的异常界面恢复可滚动页面，返回、设置和 Agent 仍可操作；成功重载后回到原沉浸布局，焦点离开已隐藏的重试控件。文字路径不补造资料，朗读和音乐仍遵循参观设置。

### 小窗与完整对话的输入衔接

小窗和完整对话使用同一份未发送文字，按账号隔离并暂存在当前浏览器标签页；切页、收起、展开完整对话及刷新该标签页可继续编辑，存储不可用时明确提示刷新可能丢失，不承诺跨设备或新标签页同步。只暂存文字和待填入的问题，照片不写入这份草稿。输入框支持原生换行并随内容增高，达到高度上限后在框内滚动，手机字号至少 16px；照片与发送按钮在同一基线。

场景提问、常用指令和方案比较有现成输入时不覆盖原文，而是在对话区展示待填入的问题，可明确追加或不用这段；没有输入时直接填入。点发送只清除本次实际提交的文字，成功后切回小窗不会复活旧草稿。失败恢复原文，但请求期间新写的文字优先保留；重试沿用原消息编号，不消耗另一条新草稿。账号切换后迟到的请求不能恢复到新账号输入框，也不能清除新账号的处理状态。窄矮屏的待填入问题放在可滚动对话区，展开不挤掉输入及发送控件；真实手机软键盘仍须现场验收。

### 在合适的时候开口

主动提示由时机规则决定是否出现，再由 Agent 根据已核实资料组织自然语言；不能让模型凭空决定用户“已经到达”或“站在某个展柜前”。同一次到访仅在以下时机候选：首次进入现场的一句欢迎；旅者主动点选元素后的针对性讲解；旅者停留且尚未探索时的一次轻提示；行程剩余时间明显变化时的参观顺序建议；离开前的笔记/下一站承接。室内展区不使用普通 GPS 自动触发，只有明确点击、楼层选择或额外经核实的定位能力才赋予室内元素上下文。

试点目前有入场欢迎语、八分钟未探索时的一次轻提示，以及本人当前日计划中该站处于“游览中”、原计划结束时间进入 20 分钟窗口时的节奏提醒。若打开现场时已临近原计划结束时间，节奏提醒代替欢迎语；随后出现仍遵循每次最多三次、相隔至少八分钟。提醒只陈述原计划与当前时钟，不产生离场事实；旅者点“请伴途帮我”后才由 Agent 核对最新计划并执行受托操作。点选元素属于旅者请求。旅者还可单独开启默认关闭的“离开范围提醒”：仅在本人当前计划站点处于游览中、现场页处于前台且定位先稳定处于候选范围内，再连续两次明显走出附近约 30 秒后，才显示“可能离开”的建议。旅者可请 Agent 核对下一站或忽略；定位不会自动完成当前站、修改计划或记入到访。页面不可见、正在与 Agent 对话或开启“安静参观”时不新增提示；主动提问始终可用。资料不确定时说清未知，不为制造陪伴感猜测开放、排队、展品位置或旅者感受。重复到访按独立 stopId 处理自动进入及离开提醒；当前现场的已探索标记仅存本次浏览器会话。

### 一句话继续行动

## 变化入口与 Agent 调整

“旅途，随心一点”的四个入口发送绑定当前身份、计划、版本、站点与交通方式的自动托管请求，进入真实 LLM 工具循环。模型先读取计划，按需求查询地点、道路与天气，选择休息时长、替换地点或结束时间，核对可执行影响后自动保存后续安排。点击入口即授权本次普通后续调整，不再要求用户机械确认候选。必要信息缺失时由模型追问，自然中文回答继续调用 LLM 和工具；原安排已满足诉求时可明确保留并解释。用户可停止处理或取消等待中的调整，成功后回首页继续；刷新保留状态与实际变更。

模型选择与业务核验各司其职：companion.preview 返回至多三份有效变更及道路影响，companion.apply 只能使用本次任务已核验的凭据。模型可以决定参数和地点，但不能用文字证明可行或保存成功；页面展示成功工具回执中的前后变化。托管工具调度只允许本次计划的核验与应用，不能绕过保护去调用普通编辑、进度、发布或删除工具。

当前托管核验只处理今天、最多八个后续地点、附近三公里目录；休息 5–120 分钟。设备定位受两分钟新鲜度约束，已确认到达的具名起点最长五分钟，供应商更短期限优先。普通Agent消息使用已有新鲜定位，不因休息或追问强制等待GPS；明确出发或更新路线时才取新定位，拒绝不伪造定位；没有可用道路或必要开放资料时不能自动保存。道路供应商确认附近起终点为零距离时可接受零路程，仍须用户报告实际到达。建议不自动跨日；未采用凭据重启后失效，已保存回执随计划保留。旧对话的 start/preview/apply/cancel 手动确认入口继续兼容，当前首页不再走此预设链路。自动托管是用户触发的一次调整任务，不是后台持续无人值守出行或替用户付款。

从地点详情顺延到后续日期时，预览先核对目标日期已有安排，将新增游览接续在已有站点之后，并核对该地点参考开放时段；目标日也排不下时，继续查找后续日期并明确展示实际日期。预览同时显示原安排与新增时段，已有安排不因新增而移时。跨日不沿用前一天的交通路线，交通保持待估，出发时重新计算。重复到访按最终归属日展示参考时段，不额外限制新增到访。确认期间原日或目标日计划变化均需重新预览；冲突说明保留在确认面板内，不写入任一天。成功后进入实际归属日期，保留目标计划原名称、已有地点和进度，不产生到访事实。

日计划编辑器替代选中日期的空状态或执行卡，避免同时出现“创建计划”和未保存编辑；日期导航保留。方案页提示日计划草稿已保留并提供返回入口，不将它显示为多天方案。方案库标题与操作独立排布，不再用外层卡片包住编辑器，日计划和方案编辑宽度一致。每个地点卡自带“前往此处”的交通方式与该段预计时间，手机以名称/删除、时间/排序、前往方式分行显示，按钮保持至少 44px 点击高度，长名称完整换行。第一站也可预先选择出行方式；起点尚未确定时，提示出发时按当前位置估算，不伪造第一段时间。

Agent 创建日计划或方案时同样逐站保存用户指定的前往方式，首站选择不依赖路线或当前位置。整天道路计算默认沿用各个目的地的选择；只有明确要求统一交通时才统一更新待进行目的地。Agent 修改一段路线后，目的地的交通选择与路线同步，不再出现回复已改驾车、页面仍显示步行的情况。没有当前位置仍不能估算首站真实路程；道路失败如实说明待估，不撤销已保存的地点与选择。

新方案预填可修改的名称，留空保存时按地点生成名称，与已有名称重复时增加序号，仍符合 40 字限制。普通选择开始时间不自动变成固定时段。时间与停留编辑先按前站结束、当前方式的已知路线与缓冲填入可用值，并顺延后续未开始地点；遇到已有固定时段或实际进度时，在可用范围内提前本次开始或缩短本次停留，显示回填说明后由用户保存。真正无足够时段、账号/版本冲突和网络失败仍保留原因，不改事实或伪造保存成功。未知交通继续待估。日计划“调整时间”与“游览景点”标题同排；桌面编辑器名称、时间胶囊与操作同排，手机时间与排序同排，胶囊内部不换行。时间标签区分游览开始与停留时长，次日偏移不因重新选择小时/分钟被清零；日期计划时间面板可选择计划当天或次日。

多日方案的时间编辑、停留调整、添加地点和道路计算跨午夜时，立即补齐所需天数。次日才开始的地点归入实际第几天，时间按该天凌晨归一化；编辑器跟随手动改时间或新添加后迁移的地点。午夜前开始、次日结束的地点保持同一次到访，次日显示“跨日延续至 HH:mm”，可返回原安排调整，不复制节点或重复计算地点数与时长。恰好 24:00 结束不额外补天。减少天数不能截断保留地点的跨日延续。已有次日地点、重复到访身份和可用路线费用保留；分天后失效的跨日路线与关联估算费用移除，已支付关联费用需先核对，真实时间冲突阻止覆盖。保存、Agent 生成和旧方案读取采用同一分天规则。日期日计划的执行迁移仍遵循三态规范 T7。

临近午夜用兼容命令安排时，自动顺延后的回复显示实际保存日期，地点分属多日时分别说明；页面跟随最早实际归属日。取消今天的计划不删除次日安排，今天的出发／到达／完成也不作用于次日地点。

同一地点允许同日或跨日反复到访，每次生成独立节点，分别保留时段、交通和进度，不按地点标识去重。编辑草稿时直接追加，不额外弹出重复确认；只有保存才写入计划。从详情直接加入已保存计划仍展示正常的时间预览，当天其他到访仅作为参考，取消、叉号和 Esc 不写入。Agent 接受“再去武康大楼”及“武康大楼、龙华寺、武康大楼”等重复安排，保留顺序；进度优先作用于正在进行或下一次待进行的到访，已有完成记录不被重置。名称匹配多次待进行到访时，改时间或时长要求指定具体节点；网络重试依请求标识幂等，不等于一次新的到访。方案批量载入沿用独立进度/替换确认。

编辑和改期提交打开时捕获的版本，冲突保留输入并要求重新核对；旧账号的迟到列表不覆盖新账号。道路查询成功可顺延可移动时段，保留游览时长和更大间隔；赶不上固定时段阻止保存，查询期间禁止保存，旧路线不能覆盖新编辑。

计划保存期间切换编辑天数、重绘页面或再次点击保存，沿用同一草稿的在途请求，不重复创建方案。按钮显示“正在保存”；失败后恢复重试。提交之后继续改名称或安排，成功回执保留新编辑并绑定刚保存的对象，不丢草稿。新笔记与帖子同样只清理实际提交内容，迟到成功不关闭后来打开的编辑器、不清除新输入或照片；保存事实仍保留并明确说明。

普通过期日计划保留原安排、完整事件及已有内容快照，转入往日记录；旧进行中保留收尾。历史按原时区过去 30 天内允许补记/纠正，之后只读。补记不预填计划时间为实际时间，实际到达选填；历史变更不导航、不改变今天或其他历史地点。详细迁移和调度见三态规范。

历史修订保留原事件和原因，关联记忆保留用户原文与旧摘要，标明来源已更新并可查看新记录；个人感受仍可编辑，不能用改文字清除摘要失效。主动删除日计划/历史说明地点、事件和快照不可恢复，私人笔记、记忆及源方案独立保留。

已有笔记或旅行记忆的编辑按主体和记录分别暂存草稿，保存前不改变原文。关闭、Esc 或“稍后继续”保留修改；刷新同一标签页后可重新打开继续，浏览器存储不可用时明确提示刷新可能丢失。“放弃修改”需确认，仅清除此条编辑草稿，原记录和其他草稿保留。个人记忆保存提交打开时的条目版本；另一页面先保存后，旧版本被拒绝且输入保留。重新打开同时展示自己的草稿与最新原文，用户核对并明确勾选后才能保存；期间原记录再变仍会拒绝。迟到保存回执不关闭新打开的面板，不将旧主体结果写进当前账号。

## 地图、路线与收藏

发现地点的关键词搜索先显示 24 条供应商结果，未输入关键词的目录页每页最多 50 条；尚有结果时显示「加载更多地点」，不会等待全部分页才展示。计数反映实际已显示地点；排序和高级筛选作用于已加载结果，后续结果可继续加载，不把第一页当全部匹配。搜索/城市/分类变化取消旧请求；重复点击复用正在进行的同一查询，迟到结果不得覆盖新查询或新账号。分页失败保留已显示卡片和游标，支持重试。计划编辑器仍使用独立完整目录，不受搜索分页影响。

发现页搜索只请求地点结果；公开收录已合并到统一目录，不重复刷新帖子、分享方案或「我的」社区内容。第一次进入发现页单独读取自己的分享状态，排序不重复请求网络。高德公开 POI 原始页最多缓存 30 秒并合并相同的在途请求；个人标签与用户评价每次重新附加，不跨账号缓存。帖子和方案关键词变化同样取消旧搜索，保持既有权限、分页和错误语义。

游客可搜索公开帖子与分享方案，长关键词和长方案码同样可用；搜索不授予发帖、评论或帖子收藏权限，私密帖不会出现在公开结果中。隐藏或撤回的社区地点不能通过直接备注／标签地址绕过地点访问限制；提交期间撤回也会拒绝旧请求，不影响已保存个人内容的归属。

地图先于路线控件展示，没计划、定位拒绝或道路失败也保留底图。首页目的地无坐标时显示区域底图及说明；底图失败保留已知图层与重试，不用直线补画道路。目录加载与地图重绘分开，离页/身份变化后拒绝迟到响应。

地图页、首页随行和实际出发共用前台设备定位。蓝点随每次更新的有效坐标移动，不要求精度逐次提高，也不在首次定位成功后停止；蓝色圆圈显示设备报告的误差。路线起点只使用30秒内、误差不超过200米的新鲜定位；粗定位、权限失败或过期立即撤销旧当前位置和基于它的路线预计时间，保留目的地及手动选点能力。地址解析独立执行，失败不阻塞坐标更新；不以旅行城市、旧地址或固定校园坐标冒充定位。地图定位按钮重新获取新位置，最多等待15秒，失败说明原因；后台暂停，回前台重新连接。

地图只画供应商返回且标明坐标系的完整道路轨迹。缺轨迹、片段断开、端点离道路过远或服务失败时不连起终点、不显示假路程与预计时间，并提供重试。起终点预览沿用当前方式，全程预览按每个目的站保存的方式规划，重复到访按站次保留。查询最多等待25秒，支持取消；切账号、改计划、改终点或当前位置明显变化后，旧响应不能覆盖新选择。自动更新蓝点和路线不夺走用户拖动后的视角，主动重新定位或选择新起终点时才调整视野。手机地点弹窗支持内部滚动，起终点按钮保持44px触摸区。

地图跟随选中日计划，圆点数字为未跳过站点顺序；目录地点与收藏不自动成为计划站。地点弹窗显示已有坐标编号，如武康大楼 `12143603120601`；网格和内部收录序号不同，坐标校正不重算旧 ID，兼容旧 10 位编号。

普通入口选择终点，站点入口自动设为目标；起点优先设备当前位置，也可明确选择其他起终点或点地图指定。真正出发尝试新鲜位置，与普通前后站预览的起点语义分开。卡片直线距离不是路网距离；全程按计划顺序串联未跳过地点，包含已完成站，不能称为仅剩路线。

交通方式共用可展开纵向选择器，超过六项提供搜索，长列表滚动，支持方向键、Home/End、Enter、Esc 和关闭回焦。清单配置不等于服务能力：新增方式须接通路线和执行契约。方案/日计划草稿在添加、排序、改时间或选择某地点的前往方式后，自动查询需要更新的相邻路段并顺延可移动站点；其他路段的方式、路线和费用保持原样。查询期间暂停保存，失败标为待估并在该地点提供重试，不填造交通时间；实际出发时仍从当前位置重估。地图查看不自动重排或记录进度。

地图与路线将“交通方式”标签放在按钮上方，与起点/终点字段一致；按钮内以图标、当前方式和下拉箭头单行排列。“公共交通”等名称不拆行，三个控件统一 48px 高，桌面同排对齐；交通列至少 180px 并随可用宽度分配空间，窄屏将起点和终点并排、交通方式独占下一行，地图保持在表单之前且高度为 260–300px。字体随大字模式缩放，超过可用空间的未来长名称省略显示，完整方式仍由按钮的无障碍名称和选择面板提供。

首页随行和计划与进度的交通选择保存到日计划节点，不依赖定位或道路估算成功；刷新、中止后再次出发仍保留，站点地图入口沿用该选择。保存期间暂停重复切换和记录进度；失败保留原选择，网络错误明确提示重新选择，多页冲突须重新核对。旧方式的路线和关联费用保留，但不能继续作为新方式的耗时；新路线可用时保存匹配的估算，缺资料仍待估。选择交通方式不产生出发、到达或完成事实。

无高德 Key 时正常服务使用 OSM 道路网估算步行/驾车，配置高德后使用高德路线及公交。不可用的公交、跨城、缺坐标或空路线保持待估，不回退成假步行分钟数；道路估算不保证实时/未来路况或场馆可达性。路线查询会向供应商发送起终点坐标。

内部与设备 GPS 使用 WGS84，高德使用 GCJ02。社区明确声明 WGS84/GCJ02/BD09 后统一转换，旧记录未注明时不猜测，作者重核并再次审核。地图与依赖权利标注保留，绘图来源见[素材说明](../public/images/places/ATTRIBUTION.md)。

地点收藏独立于计划，游客可用；帖子收藏需账号。取消收藏不删除计划，快照不保证最新。私人标签、备注和收藏按主体隔离；私密帖仅作者可读，公开转私密移除他人收藏，再公开不恢复。

地点私有备注最多 500 字，输入按账号与地点暂存于当前标签页；关闭或刷新该标签页后可继续，保存失败不清空。成功保存才移除相应草稿，清空并保存即删除已存备注。存储不可用时提示刷新可能丢失；不承诺跨设备草稿同步或并发编辑防覆盖。

帖子评论与回复的未发表文字按账号、帖子及回复对象在当前标签页暂存；刷新或跨页返回可继续，点赞等重绘保留回复展开状态，正在编辑时保留焦点与选区。发送失败在对应输入处提示重试，成功仅清除已提交的那份文字，等待期间写的新内容保留。浏览器存储不可用时仅保留当前页面并说明刷新限制；不承诺跨设备或新标签页恢复，也不将草稿公开发布。

点赞、发表评论及删除评论按帖子分别等待，同一帖子的完整回执依次应用，避免互相覆盖；不同帖子可以同时操作。等待立即显示在按钮或评论区中，重绘、切页返回仍保持等待，重复触摸不再次发送。收藏独立等待，不阻止评论或另一帖子的收藏；账号切换后的回执不应用到新主体。操作失败恢复按钮，评论草稿保留，可再次发送；切页后的收藏回执不弹出旧页面的成功提示。

发现地点的数量以当前查询、分类及高级筛选后实际展示的卡片为准，不使用筛选前目录数量。查询中显示进度，失败显示重试并保留关键词与条件，不能用旧卡片或“没有结果”冒充本次查询成功。连续搜索只接收最新请求的目录与标签；切换主体后拒绝旧结果。真实空结果提供恢复入口：“清除搜索”只清关键词，“放宽筛选”取消分类和设施、费用、时长、评分条件，保留城市、关键词及排序；“调整筛选”展开并聚焦原筛选区，不跳走。窄屏与大字下恢复按钮等高并排，操作不改收藏、计划或执行事实。

地点详情的开放状态只按收录的每日时段与上海当前时间推算，明确显示“参考时段内／外”“全天时段 · 参考”；缺少或无效时段显示“开放时间待核实”。不将时段匹配称为实时营业或闭馆，休馆日、预约限制与临时调整仍需行前核实。结束时刻不算时段内，跨午夜时段显示次日时间；页面停留时只刷新状态文字，不重绘或打断编辑。定位不可用的出发确认面板将“我已出发，先记录”放整行，重新定位与取消并排且等高，未知路线仍保持待估。

## 社区、账号与公开范围

评论、回复、发帖、地点分享及评价不收集昵称，统一使用账号资料；仅“我的”支持主动修改昵称。游客可读公开内容，写评论引导登录，发布及评价入口先登录。

帖子正文纯文本，可关联最多 12 个目录地点和四张照片；浏览器压缩 JPG，单张不超过 400 KB，总量不超过 1.2 MB，存应用数据，不使用外部图片链接。帖子可选公开或仅自己可见，随草稿保存；私密发布进入“我的发布”，卡片/详情标识清楚，作者可修改“可见范围”。正文、照片、评论、链接和收藏由服务端校验，Agent 同样遵守权限。历史缺省为公开，异常保存值恢复为私密。

帖子详情的关联地点使用定位图标与地点名组合的轻边框按钮，不重复显示“查看地点”；同组最小高度 44px、12px 圆角及 8px 间距，长名称完整换行。图标与名称作为整体居中，名称对应原地点标识，点击查看资料，返回仍回原帖；屏幕阅读器明确读出“查看地点：名称”。

公开帖子搜索覆盖完整公开集合的正文及昵称，不能只筛已加载的第一页；私密内容只在作者的“我的发布”中查找。搜索中显示进度，失败保留关键词并提供重新搜索，不显示假空结果；清除搜索与搜索按钮等高同排。加载更多防止重复请求，失败保留已有记录并可重试，查询或账号变化后的迟到响应不得追加。返回帖子列表保留查询、筛选和已读范围，并重新核验至原最旧记录的时间/ID 边界，移除已撤回或转为私密的记录；新帖插入后优先恢复原帖的屏幕位置，用户滚动或改变页面、筛选后停止追随。详情照片可点击放大，关闭或 Esc 回到原帖；点击关联地点再返回，继续查看原帖及原搜索结果。上述阅读位置仅保留当前页面会话，不承诺刷新后恢复。

后台加载完成不得在鼠标或触控按压过程中替换整页控件，避免一次点击被重绘吞掉。延后重绘至按压结束及原生点击分发后，以最新状态合并更新；取消手势或窗口失焦也解除等待，键盘操作照常响应。

帖子详情在手机上将点赞、收藏、可见范围和撤回排列为两列，保持完整标签与等高点击区；非作者只显示有权限的操作。记忆编辑在 360px 及以下让“保存修改”独占一行，继续和放弃并排，同组按钮最小高度 48px；核对最新原文的确认行至少 44px，深色与大字下可滚动查看完整内容。

公开帖可点赞、评论、回复；点赞再次点击取消，只能删自己评论，有回复的被删评论保留占位。作者可撤回帖子；公开撤回帖的已有收藏保留为撤回快照，私密变更则移除其他人快照，两者语义不同。

方案分享先看名称、城市、天数、每日地点/时段及可展开地图位置，再明确公开发布；取消/Esc 不提交，空白天保留。私人笔记、实际进度、费用及具体出行日期不进入分享，原账号或方案变化要求重预览，重复点击不重复发布。

地点发现须经平台审核才进入公共目录，伴途“平台收录”不表示已向高德或文旅机构报送。未核实内容仅作者可读，评价不能证明设施或开放准确。

| --- | --- |

作者撤回后退出目录，已有计划历史快照不随之消失；同城同名重复拒绝，尚无合并工具。运营方通过“我的 → 高级信息 → 平台地点审核”进入审核页，凭证验证通过后才展示待审、举报线索和处理记录。审核面板展示地址、来源坐标系、坐标、介绍及核实依据，要求人工核对，填写说明并再次确认收录或退回。退回仍仅作者可见，作者可按说明补充后重新提交；收录进入公共目录和完整地点详情，未提供的设施、时段和费用保持未知。新版审核请求携带申请版本，资料重提或状态变化后旧决定返回 409，说明保留并提示刷新核对。说明草稿按账号、申请及版本暂存，关闭/Esc 可继续；断网保留确认与说明，可重试。审核凭证只保存在页面内存，退出或刷新清除，不进入 URL 或浏览器存储。举报线索目前只读，不自动撤下地点或标记已处理。未配置凭证时申请仍可提交，但无法作出审核决定，不承诺处理时限。

注册账号保留原游客主体及资料；登录已有账号切换且撤销原游客会话，不合并。游客默认会话期限 30 天，清除站点数据、过期或切换后不承诺找回；已有账号重新登录可读原资料。会话失效提示跨页/本标签刷新保留，关闭或登录成功后收起。尚无密码找回、邮箱验证、第三方登录。账号配置和体验账号见[运行与部署](运行与部署.md)。

## 视觉、可访问与失败体验

局域网邀请测试使用独立门禁页：输入本次邀请码后进入应用，再使用自己的游客或账号身份。每次重新开放生成新码并撤销旧通行 Cookie，保留原账号和数据；本机回环页面不受邀请门禁影响。关闭局域网后恢复仅本机访问。HTTP 下缺少浏览器原生 randomUUID 时，方案导入、分享预览、候选采用和路线节点仍可生成独立标识；实时定位和 PWA 受浏览器安全上下文限制，仍显示真实降级，不伪造定位。操作入口与设备测试边界见[运行与部署](运行与部署.md)。

采用明亮、轻快的年轻旅行风格，保留原足迹翻面和中文标题，不加 Travel Journal。首页灵感、发现地点和收藏共用 `placeCard`：印象图宽高比固定为 2:1，整卡宽高比固定为 3:4（宽:高），实际宽度随屏幕和容器自适应，高度按该比例计算。同一屏宽下三个入口的卡片宽、高相同，长短内容不改变尺寸；地点网格使用整齐行列，不参与内容卡片的按高度补位。三个入口共用宽度与内容区规则：980px 以上三列，621–980px 两列，620px 及以下单列，列宽填满容器。标题预留两行，简介至多六行并按可用空间收拢；停留时间与费用参考在下部并排，只使用目录资料，未知时明确显示“暂无资料”，设施保留统一行位。地址与收藏同排，按钮至少 44px 高，底栏位置一致；地址仍可点击进入详情，完整资料在地点详情查看。这替代早期地点卡自然高度与补位规则，其他内容卡仍按信息量确定高度。现行 27 张印象原图均为 2:1，其中 10 张 AI 重绘统一标题和描述；印象插画不作为导览位置依据。

卡片按信息量组织，不靠大块空白撑高。首页头图收紧内边距与插画尺寸，手机快捷卡改为图文并排；足迹卡按当前可见的一面自然撑高，隐藏面不占布局高度，保留原翻面动画。随行桌面将路线与临时调整放在独立右栏，内部依内容紧凑排列，不通过跨行拉伸让两侧强行等高；计划时间、游览时长和开放信息在空间足够时并排。后续站点放在下方整宽横栏；随行与地点网格共用 980px／620px 两列与单列断点。首页当前站点是行程操作卡，印象图仍为 2:1，卡片高度按本站信息和操作自然撑开，取消 3:4 整卡比例及内部弹性补空。显示地点名称、地址、时间、交通和当前执行动作，不用介绍文字补满留白；长信息跟随页面滚动，地图保留可操作高度。普通地点目录卡继续保持 3:4。旅程概览仍在卡片外。帖子、收藏帖子、笔记、往日记录与旅友评价在 1360px 及以上三列、621–1359px 双列、620px 及以下单列；方案库保持宽屏双列，以容纳同排操作与载入日期；多卡片按实际高度向上补位，减少短卡片下方的行间空洞，图片加载、展开及文字尺寸变化后重新计算，保留原 DOM 和键盘顺序。单列、方案编辑器、空态与失败说明使用普通布局，编辑器及说明始终占整行。地点详情的实拍照片与实用信息在 1100px 以上并排，较窄屏幕恢复上下排列；手机实用信息按一行一个项目组织，标签和值并排，地址完整换行，私有备注仍可编辑。地图地点列表不固定 164px 高，也不为空短标题保留两行高度。发现地点目录说明使用紧凑标题区，推荐说明与操作同排；“我的”页将账号与游客提示并排、通用/AI/维护分组，按屏宽切换三列、两列或单列。空态依内容撑开，标题与分区间距收紧，按钮仍满足点击尺寸。1200px 及以上首页将欢迎/足迹卡与纵向快捷入口并排，较窄屏恢复上下排列；原首页功能与翻面保留。901px 及以上的日计划卡将地点和状态放在左侧，路程与游览信息放在右侧，操作单独一行；单阶段或较窄屏仍按自然顺序纵向展示，长文字完整换行。

首页无计划及安排冲突提示采用横向卡：图标、标题与说明在左，操作在右；620px 及以下操作独占下一行，两按钮等高并排。该提示依内容撑高，避免宽屏仍采用居中的多层堆叠；保留开始规划与核对安排的入口。

「我的 → 通用 → 简约模式」默认关闭，开启后已有图标和文字的操作按钮只显示主要图标。偏好保存在当前浏览器，刷新与切页继续生效；关闭后恢复原图文样式。图标按钮保留无障碍名称、提示、禁用与选中状态，点击区域至少 44px，同组采用 8px 间距；底部导航保持等宽分布。纯文字按钮、昵称、交通方式选项列表和表单说明保留文字，避免凭空生成含义不明的图标或隐藏必要信息。首页快捷入口、随行调整、计划及方案操作在简约模式下按图标尺寸重新排列；地点卡仍保持 3:4、印象图 2:1。手机 Agent 快捷指令使用两列等宽排列，长指令独占一行；这些入口仍使用原指令内容。

区分空数据、加载失败、权限拒绝和版本冲突；处理期间防重复，错误保留输入，账号/页面变化后旧响应不写回。离线可看已取得内容和本地图，不能宣称新路线、天气或写入成功；不后台无限重试修改。照片可选择、压缩、预览、清空及单独发送，失败保留草稿，停止说明只停后续。

同一浏览器的标签页共享登录 Cookie。另一页切换账号后，旧页显示原账号与“读写已暂停”，保留正在编辑的内容，不自动刷新。新账号核对优先于之前尚未返回的核对，旧资料不能解除保护。可打开账号页切回原账号后继续，或明确刷新到当前账号；已暂存的计划草稿按原主体保留，本标签页切回原账号后可继续；无法暂存时另提示刷新可能丢失最新修改。恢复原账号后，更早的业务回执不能切换会话、覆盖新草稿或关闭后来打开的设置；已经提交的业务可重新查看结果，不重复执行。同账号的普通昵称等资料刷新仍保留合法回执。保护提示中 Tab 保持在可操作按钮内，Escape 不关闭底下编辑框。即使标签页变更通知失效，服务器仍核对请求的页面主体并拒绝错账号写入；切回原账号不把另一个账号的资料混入旧页。

启动期间遵循用户最后选择的页面，迟到的初始化结果不能拉回开始时的路由或清空编辑内容。已显示可用页面时，10 秒等待提示在页内出现，不替换编辑框或叠加遮罩；可继续等待、收起提示继续编辑，或明确重新加载。迟到的成功加载收起提示并保留文字、焦点及选区。重新加载仍可能丢失未保存输入，不将保留当前页面等同于保存成功。模块完全未执行时，独立脚本在 6 秒后提供恢复入口；明确的启动错误页已显示时不再叠加第二层恢复提示。

## 当前Agent对话和休息体验（2026-10-02）

只有完整Agent页提供「当前对话」和「新对话」，同组56px等高。列表显示可修改的名称、最近消息、消息数量、具体日期时间与当前标记；不展示容易误认为ID的装饰序号。简约模式保留当前对话名称与列表中的全部辨认信息，只精简新建等操作按钮；当前对话栏和新建按钮仍为56px等高。命名、删除均为44px图标按钮；删除先显示准确名称及范围，确认后清除该段聊天、附件和任务检查点，已保存的计划、帖子、笔记及收藏保留。删除最后一段会生成可用的空对话；已删除的原始对话不再出现。悬浮小窗不显示新建、切换、命名或删除入口，继续当前对话。切换恢复各自输入草稿和消息，刷新保持所选对话；处理或上传期间暂不切换，执行中的对话须先停止任务才能删除。所有对话仍访问同一账号的业务数据，并按账号权限重新读取。「随行托管」是首页调整来源的内部标签，界面移除该标签，保留实际调整结果与必要追问。

Agent保存笔记或准备发布帖子时，第一行是标题、后续各行是正文。模型工具优先传独立title与正文text；旧格式仍允许text包含完整多行原文。仅提供一行时可保存为只有标题，不虚构正文。用户明确引用完整原文时，工具在保存前核对组合文字，重复标题或改写原文会要求模型纠正；原文确实重复时仍保留。确认删除等短答不丢掉原委托中随后保存笔记的要求，笔记里提到“方案”也不会触发额外规划。帖子预览分别显示标题、正文与可见范围，再等待确认发布；不能只把正文传给工具导致标题丢失。

Agent支持“仅自己可见／private”的帖子发布和本人帖子可见范围修改。私密请求不因模型漏填范围而变成公开；标题、正文中的相关词语只是内容，不当成设置指令。范围修改先显示准确帖子、当前范围与目标范围，确认后提交；原范围发生变化须重新核对。私密发布后可通过成功回复的“查看帖子”进入作者详情，其他账号无法从列表、详情或收藏快照获取该私密内容。

一条指令明确要求保存多篇原文时，分别核对每篇的标题、正文、所属类型和独立保存结果；帖子与笔记不能互换内容，预览不算发布完成。要求两篇相同原文仍分别保存，已经成功的篇目在确认或继续时不重复创建。缺少任何一篇时，Agent有限纠正后明确说明未完成部分；可恢复中断保留续办入口，原生上下文超限或累计硬上限则关闭该检查点并提示新对话或重新委托，不能反复“继续”同一超限任务，也不只口头宣布全部完成。多份方案也分别遵守各自天数和每日地点数，后续收藏、比较或删除旧方案不取消创建要求。

已完成、已停止和已终止的任务不因单独输入“继续”而重新执行；回复说明当前状态，保留实际成功结果入口。明确提出“再保存一份”等新需求仍能创建独立对象；超时等可恢复中断继续原任务，确认及续办始终绑定同一对话。

用户明确要求“只解释／不要保存”等只读操作时，服务端拒绝不符合要求的写入；明确不要修改或删除笔记、计划等内容时，不因同一句另有收藏要求而放开被禁止的动作。只读某类内容与另行明确委托收藏等动作可分别处理，无范围的禁止写入仍约束全部写入。笔记或帖子原文里的这类文字仍只是内容。待确认时说“取消，不要保存”直接取消，不再启动模型生成额外笔记；取消后要求解释时，可以解释原预览，但不能提交已取消操作。确认期间对象发生变化时，保留原委托与已经成功的操作，提示重新核对；继续处理须重新展示有效预览，不直接沿用失效确认，也不让已完成篇目重复保存。

「想休息半小时」「累了，先歇一会」应读最新计划并实际保存后续弹性安排，未指定时长可采用30分钟并说明。原地休息不必获取GPS或查询道路；查看附近休息场所和重新估算路线才需要相应定位及供应商资料。保留现有到访事实和受保护安排，无法调整明确说明原因。回复中的完成状态以工具保存回执为准；不能用饮水建议代替用户委托的计划调整。上下文不再限最近16条，采用1M应用预算和完整旧轮次裁剪；用户接入模型仍受供应商原生容量限制。

地点目录只展示具有实际本地印象图的地点。缺图或占位素材先从目录排除，完成插画后才能恢复收录。当前27个地点均满足素材条件；不误删已有印象图或历史到访。

官方模型存在但不支持本人的思考偏好时，Agent明确显示原因及「服务设置」，不显示成已经可用。GLM-5.3-Flash不能关闭思考；设置禁用不支持的关闭选项，仍允许本人明确选择开启与较轻／深入。保存后立即更新当前页面的服务状态；不自动改变本人、其他账号或官方偏好。悬浮小窗使用简短说明，输入框和聊天记录保留空间。完整页说明与会话栏、聊天区、输入区各占独立布局，不能覆盖点击区域。休息后报告具体时间时，开始与结束须按成功工具回执分别说明。
