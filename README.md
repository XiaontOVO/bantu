> **专心逛，随时问，随时改，走完留下自己的旅行。**

伴途面向自主安排半日到一日城市漫游的人，适合城市散步、建筑探访和看展。途中累了想休息，到了景点想知道眼前值得看什么，走完想留住自己的感受——这些需求都在手机上接着处理。

伴途的重点是**把临时变化落实到正在进行的旅程**：Agent读取当前计划与进度，调用工具保存调整，旅者随后能继续出发、参观和记录。当前以上海城市漫游为原型范围，优先为移动端设计。

## 三个核心体验

- **旅中，随时改安排。** 一句话委托Agent调整原计划的后续时段；休息调整保留已完成站点与执行记录，改完继续原旅程。地点搜索、可复用方案、逐站交通与地图路线支撑安排和执行。
- **现场，边看边问。** 横屏艺术场景中点选元素，展开讲解文字与音乐；可移动的伴途小窗结合当前页面、地点和元素回答，原页面继续可操作。需要找路或查资料时，查看地图、场地及楼层图。
- **旅后，留下自己的旅行。** 到访记录对应私人回顾，Agent可补写本人原话；旅行成就展示到访来源，公开或私密发布由本人选择。

### Agent怎样接住当前界面的任务

新版视频依次展示：在地点详情说“把这个地点加入今天的计划”，在地图说“去这里改为驾车”，在场景追问眼前红砖，在首页委托休息半小时，再在私人回顾补写本人感受。小窗结合当前页面处理请求，结果回到计划、路线或记录里核对；收起小窗就能继续原页面。

例如，第一站已经逛完后委托休息半小时，Agent在**同一份计划**中将后续两站的开始与结束各顺延30分钟，已完成站点和原有执行记录保持，随后继续出发。地点和地图两段另用真实模型补录，展示实际保存的45分钟停留与驾车路段。

请求、处理状态与结果同帧放大，保留操作原速；剪短的等待、独立示例及模型回复与字段不一致均有说明。详细版保留方案编辑等更完整流程，具体覆盖见[作品说明与演示](docs/作品说明与演示.md#导演剪辑版跨界面-agent-辅助)。

## 运行与体验

**本地启动：** 安装Node.js 22或更新版本。Windows可双击 `启动伴途.cmd`；也可在项目目录运行：

```powershell
npm ci
npm start
```

启动后访问 `http://127.0.0.1:8787/`。Windows停止用 `停止伴途.cmd`，排障用 `诊断伴途.cmd`。

**Android体验：** [下载测试版 APK](https://github.com/XiaontOVO/bantu/releases/download/submission-2026-10-05/bantu-android-test.apk)，首次打开需接入可达的伴途HTTPS后端。Android复用网页的前端与业务服务；安装、配置和邀请测试见[运行与部署](docs/运行与部署.md)。

GitHub提供源码与演示材料，动态在线体验尚未开放。公开版本不包含模型/地图密钥、用户数据库或本机配置；真实Agent与高德能力需配置自己的服务。APK与PWA也需要后台服务。
