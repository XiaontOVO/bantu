# 伴途 · 智能旅行伴侣

> **让每一步，都跟得上真实旅途。**

伴途面向自主安排城市散步、建筑探访和看展的人。途中想休息或改变停留，一句话委托Agent调整原计划、保留已发生的进度，再继续出发；到地点后点画中元素看讲解，在不遮断页面的小窗随时提问；完成后打开对应私人回顾，补写本人感受，分享由本人决定。**专心逛，随时问，随时改，走完留下自己的旅行。**

需求重点是旅中不断重新决策、现场理解与私人整理；依据旅中信息行为研究和持续产品内测提出，不用“有多少人旅游”代替需求验证，也没有已测得的省时或用户收益数字。具体论证与功能覆盖见[作品说明与演示](docs/作品说明与演示.md)。
地点搜索、无日期方案、日计划、收藏、私人记忆和公开/私密帖子均可使用，不要求先创建旅行实例。实际出发、到达与完成由用户报告，定位和预测不自动产生事实。

产品以手机行中使用为主：地点现场、地图、计划进度和伴途 Agent 优先按竖屏、单手操作与前台定位设计；桌面端用于行前整理和演示。地点现场只在用户开启后依据稳定定位给出到场或可能离开的提示，定位不会替用户完成进度。

安卓端沿用同一套前端与后台，通过系统 WebView 运行。[Android 测试版 APK](https://github.com/XiaontOVO/bantu/releases/download/submission-2026-10-05/bantu-android-test.apk) 已构建、签名并安装到项目专用模拟器，交付包与源码绑定已核验。真实官方模型已在APK完成同计划调整、进度保留和私人回顾补写；另有门禁、账号/私密内容、会话、横屏/BGM、图纸放大与返回、冷启动及朗读证据，平台夹具验证定位授权和文件上传。本轮核心任务已完成模拟器验收；GPS、道路、时钟为演示夹具，现场、弱网、中文组合输入和听感仍待实机。首次打开需填写自己的伴途 HTTPS 服务地址，仍按服务端规则验证邀请码及账号。APK 不含后台、用户数据库或模型密钥，也不能代替服务部署；当前电脑服务仍仅本机可用，安装 App 不会自动开放局域网或外网。安装、接入及 USB 方法见[运行与部署](docs/运行与部署.md#android-测试版安装与服务接入)。

## 快速开始

Windows 安装 Node.js 22 或更新版本，双击根目录 `启动伴途.cmd`。首次安装依赖并构建，随后访问 `http://127.0.0.1:8787/`。停止用 `停止伴途.cmd`，排障用 `诊断伴途.cmd`；默认数据保存在 `data/bantu-state.sqlite`，重启保留。

同一 Wi-Fi 下邀请测试，双击 `开放局域网测试.cmd`，将窗口显示的局域网地址和本次邀请码给测试者。每次开放生成新码、撤销上次通行；`关闭局域网测试.cmd` 恢复仅本机访问，保留本机服务与数据。详细步骤及定位限制见[运行与部署](docs/运行与部署.md)。

校园网限制设备互访时，可改用个人热点，或在伴途运行后双击 `开放外网邀请测试.cmd` 获取临时 HTTPS 地址与随机邀请码。`关闭外网邀请测试.cmd` 关闭隧道，本机服务继续运行。窗口实际检查邀请页后才报告可用；远程设备仍需实测。

~~~powershell
npm install
npm run check
npm run smoke
npm run recovery
python -X utf8 scripts/check_planning.py
npm start
~~~

测试期默认使用当前服务器 API 提供伴途官方 Agent 服务。账号可在「我的 → Agent 服务」自行接入支持工具调用的 API，仅影响自己；密钥独立加密保存，可切回官方或删除。在线能力依服务配置及网络，无高德 Key 时使用本地地点目录和 OSM 道路估算步行/驾车。PWA 是界面外壳，仍需本地服务。本地地址不能作为远程评审入口；完整产品视频约10分59秒、12章、33段字幕，已生成并核对编码、字幕与音轨；精华片保留为辅助；源码及演示材料通过GitHub公开发布，动态在线体验尚未开放，不将邀请部署配置写成已经上线。

## 项目结构

| 路径 | 内容 |
| --- | --- |
| `src/domain/`、`src/services/` | 领域规则、计划、随行、Agent 和业务服务 |
| `src/server/` | HTTP 接口、会话与静态服务 |
| `src/providers/`、`src/persistence/` | 模型/地图/天气适配器及内存/SQLite 存储 |
| `public/` | 浏览器应用、自绘图标、本地插画和图纸 |
| `android/` | Android WebView 客户端、服务地址校验与原生能力适配 |
| `tests/`、`scripts/` | 自动化、隔离 GUI、启停、恢复和文档检查 |
| `docs/` | 产品、工程、规则、验收及作品材料 |

当前为可本地运行的原型。工程测试不等于真实模型、供应商、场馆现状、用户收益或生产运营已经验收；具体边界在现行文档维护。
